# wantaekchoi.github.io

[English](README.md) — GitHub Actions가 매 실행마다 렌더링하고 서명하는
신원·크리덴셜 엔드포인트: <https://wantaekchoi.github.io>

```bash
gh repo create <your-username>.github.io --template wantaekchoi/wantaekchoi.github.io --public --clone
cd <your-username>.github.io && ./setup.sh
```

`setup.sh`가 이름을 검사하고, 키를 만들고, 백업 시트를 어떻게 하라고 알려준다.
그 뒤로 손으로 고치는 것은 없다.
